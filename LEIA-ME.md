## Testar no Linux
Em um terminal aberto nesta pasta:

    python3 -m http.server 8000

Depois acesse http://localhost:8000 no navegador.

## Publicar
No Vercel, importe a pasta do projeto ou envie os arquivos do repositório a um projeto sem framework (site estático). Não requer build command; diretório de saída: raiz do projeto.
No Netlify, publique a pasta do projeto diretamente, sem comando de build.

Depois de publicado, use a URL pública final para gerar o QR Code. A página de referência fornecida foi utilizada como inspiração junto às prévias do chat; a URL de referência não é a URL da página da Mariana.
